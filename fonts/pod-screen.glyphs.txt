# PodScreen, the mPod screen font. Drawn by hand on a pixel grid for this project.
#
# One block per character. The first line is the code point and the character.
# Every block then has 17 rows, each with a zone mark, a space and the pixels:
#   ^  3 rows for accents above capitals
#   |  3 rows up to cap height
#   x  8 rows of x-height, the last one sitting on the baseline
#   v  3 rows of descender
# # is ink and . is empty. A block's width is the advance, less the 2 pixels the
# builder adds after every character. Narrow letters carry extra side space in
# their own blocks. Run: node fonts/build-font.mjs
